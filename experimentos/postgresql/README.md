# Prova de conceito PostgreSQL

Scripts experimentais executáveis separadamente do frontend. Ver a seção "Prova de conceito PostgreSQL" no README da raiz para ordem de execução.

- 00: cria a base (executar conectado a `postgres`).
- 01: estrutura e view; aplicar somente em banco de demonstração novo.
- 02: funções PL/pgSQL.
- 03: dados fictícios de demonstração.
- 04: testes funcionais transacionais (ROLLBACK).
- 05/06: experimento opcional de concorrência em duas sessões; **grava alterações**.
- 07: consultas de inspeção.

Não representa integração com o frontend.
